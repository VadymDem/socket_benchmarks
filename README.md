# Сокет-бенчмарк (лабораторна робота, C)

Порівняння режимів роботи сокетів та вимірювання швидкодії:

| Параметр | Значення |
|----------|----------|
| Домени | `AF_INET` (TCP, loopback 127.0.0.1) та `AF_UNIX` (локальні сокети) |
| Режими | `sync` (блокуючі сокети) та `async` (неблокуючі + `select()`) |
| Навантаження | `W1` багато малих (50000 × 128 Б), `W2` середні (2000 × 16 КБ), `W3` мало великих (150 × 1 МБ) |
| Метрики | повідомлень/сек, байт/сек, час встановлення з'єднання, час відкриття/закриття сокета |

## Збірка

Windows (MinGW-w64 GCC):

```
build.bat
```

або вручну:

```
gcc -O2 -Wall -Wextra -o sockets_bench.exe sockets_bench.c -lws2_32
```

Linux/POSIX:

```
gcc -O2 -Wall -Wextra -o sockets_bench sockets_bench.c -lpthread
```

## Запуск

```
sockets_bench.exe > results\run1.txt
```

Програма виводить CSV-рядки:
- `OPENCLOSE,<домен>,<k>,<сек>,<оп/с>,<нс/оп>`
- `CONNECT,<конфігурація>,<k>,<мкс в середньому>`
- `TRANSFER,<конф>,<navantazhenya>,<msg_cnt>,<msg_size>,<байт>,<отримано>,<сек>,<MB/s>,<msg/s>,<B/s>,<з'єднання мкс>`

## Файли

- `sockets_bench.c` — вихідний код (портативний: Winsock2 / POSIX)
- `build.bat` — збірка на Windows
- `results/run1.txt` — вихідні результати вимірювань
- `Звіт_ЛР.md` — міні-звіт з таблицями порівнянь та висновками
